---

Backend .NET developer based in Giza, Egypt. I build and ship backend systems
using ASP.NET Core, clean architecture patterns, and event-driven design —
and I take them all the way to production: VPS, Nginx, SSL, CI/CD.

Most weeks look like this: a microservice that needs proper inter-service
communication via RabbitMQ, an auth system that needs JWT with refresh tokens
and role-based access, a Clean Architecture solution where someone put
business logic in the controller. That is the work. I find it satisfying.

I have also led AI-native product strategy for an EdTech platform and
integrated Google Gemini into production APIs.

## What I work with

- **Backend** ASP.NET Core 8/10. Web API, Minimal APIs, SignalR for real-time.
  Vertical Slice Architecture and CQRS with MediatR — one feature per folder,
  easy to find, easy to delete.
- **Data** EF Core and Dapper where raw SQL matters. SQL Server mostly,
  PostgreSQL when the client already lives there.
- **Messaging** RabbitMQ with MassTransit. Event-driven services that stay
  decoupled as the system grows.
- **Auth** ASP.NET Core Identity, JWT access + refresh tokens, RBAC.
  Deployed behind a YARP reverse proxy for API Gateway routing.
- **DevOps** Docker, Nginx, Certbot for SSL. GitHub Actions and Azure DevOps
  for CI/CD. Ubuntu VPS for production hosting.
- **AI** Google Gemini API integration. LLM-powered chatbot endpoints
  in production.
- **Editor** Visual Studio and Rider, depending on what the project needs.

**[UniversityManagementSystemMicroservice](https://github.com/OmarAlfar0uk/UniversityManagementSystemMicroservice)**
Distributed 11-microservice university platform — YARP API Gateway,
RabbitMQ/MassTransit event bus, 10 separate SQL Server databases,
JWT across all services, integration and unit test suite.

**[ZakirPro](https://github.com/OmarAlfar0uk/ZakirPro)**
School management API on .NET 10. Automatic exam auto-submission via

role-based access for SuperAdmin, Admin, Teacher, Assistant, Student.

Education platform for children with autism. Lesson tracking, communication
cards, activity and performance records, TTS content, and a Google Gemini
AI chatbot endpoint.
